CyberSentinel-Security-Analyticsr Explanation: The KNet CyberSentinel Security Analytics Hub, developed by Randy Singh from Kalsnet KNet Consulting Group, is a single Streamlit web application that brings six cybersecurity use cases together in one dashboard. You choose a use case from the sidebar menu and pick one of three data options: synthetic demo data, which is now shown in full in a scrollable table; real data uploads using a downloadable CSV template; or live checks against hosts you own. Each use case has five tabs called Use Case Explained, Fields and Formulas, Results and Charts, Diagrams and Export Results. The hub covers six use cases. Use case 1: the Secrets Leak Scanner, which finds leaked passwords, API keys and private keys using pattern rules and Shannon entropy. Use case 2: the Container Security Scanner, which ranks container vulnerabilities by CVSS score, exploit availability and fix availability, and grades Dockerfile hygiene. Use case 3: the AI Agent Firewall, which inspects outbound AI agent traffic for secrets, card numbers validated with the Luhn checksum, personal data and prompt injection phrases, then decides to Allow, Review, Redact or Block each request. Use case 4: AI Endpoint Exposure, which scores exposed AI services such as Ollama, Open WebUI and Jupyter on internet exposure, authentication, encryption and version. Use case 5: Uptime and Availability, which measures availability, MTBF, MTTR, Apdex and error budget against an SLA target. Use case 6: Attack Path Analysis, which uses Dijkstra shortest path and betweenness centrality to find privilege escalation routes to Domain Admins. Application is built in Python with Pandas and NumPy for analysis, Plotly and Matplotlib for charts, NetworkX for graph analysis, Graphviz for diagrams, and ReportLab and python docx for PDF, Word, Text and CSV reports. Its design draws on open source tools such as Gitleaks, Betterleaks, Trivy, DockSec, Pipelock, AIMap, Uptime Kuma and BloodHound. The Real World Benefits: include preventing account takeover from leaked keys, focusing patching effort on exploitable flaws, stopping data exfiltration by AI agents, protecting self hosted AI services from abuse, proving service levels to clients, cutting ransomware attack paths at their choke points, and supporting compliance with standards such as SOC 2, ISO 27001, PCI DSS and GDPR. All of this comes in one easy hub that both technical teams and business leaders can use.
