The KNet CyberSentinel Security Analytics Hub, developed by Randy Singh from Kalsnet KNet Consulting Group, is a single Streamlit web application 
that brings six cybersecurity use cases together in one dashboard. You choose a use case from the sidebar menu and pick one of three data options: 
ynthetic demo data, which is now shown in full in a scrollable table; real data uploads using a downloadable CSV template; or live checks against hosts you own. 
Each use case has five tabs called Use Case Explained, Fields and Formulas, Results and Charts, Diagrams and Export Results. The hub covers six use cases.
